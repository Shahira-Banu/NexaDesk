# NexaDesk – IT Helpdesk Management System

NexaDesk is an IT Helpdesk Management System designed to simplify IT support operations by providing a centralized platform for managing technical issues, tracking support requests, and improving communication between users and IT support teams.

The project follows a frontend–backend architecture, keeping the user interface and server-side application logic organized separately.

## 🎯 Project Objectives

- Centralize IT support request management.
- Simplify the process of reporting and tracking technical issues.
- Improve communication between users and IT support teams.
- Organize helpdesk operations through a structured application.
- Provide a maintainable and scalable foundation for IT service management.

## 🏗️ Project Architecture

```text
NexaDesk/
```

| Component | Description |
|---|---|

| Backend | Handles application logic and server-side operations. |

## ⚙️ Core Modules

The system is intended to support the following helpdesk workflows:

- **Ticket Management:** Create, track, and manage IT support requests.
- **Issue Tracking:** Monitor the progress of reported technical issues.
- **User Management:** Organize users and support team access.
- **Support Workflow:** Manage requests through their resolution lifecycle.
- **Dashboard:** Provide an overview of helpdesk activities.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Shahira-Banu/NexaDesk.git
```

### 2. Navigate to the Project

```bash
cd NexaDesk
```

### 3. Set Up the Backend

```bash
cd backend
```

Install the required dependencies according to the backend configuration.

### 4. Set Up the Frontend

Open another terminal:

```bash
cd NexaDesk/frontend
```

Install the required frontend dependencies according to the project configuration.

### 5. Run the Application

Start the backend and frontend using their respective development commands.

Refer to the individual project configuration files for the exact commands.
